# MachineLearning
# Glass Classification ML Project

## Description
This project compares multiple machine learning models on the Glass dataset.

## Steps
- Data validation
- Missing value handling
- Feature scaling
- Train/test split
- Model training
- Evaluation using Accuracy and F1-score

- ## Dataset

This project uses the Glass Classification dataset, available on Kaggle:
https://www.kaggle.com/datasets/uciml/glass

## Models Used
- Logistic Regression
- SVM
- Decision Tree
- Random Forest

## Best Model
Random Forest achieved the highest performance.

## Metrics
Accuracy and Weighted F1-score were used due to multi-class classification.

## Output
- model_report.txt
- confusion matrix plot
